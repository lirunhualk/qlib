# 雪球数据源评估

评估日期：`2026-07-26`

## 结论

本机没有授权的雪球历史帖子文件或实时数据流，因此当前不能生成可信的雪球策略收益。

雪球公开页面可人工浏览，但其现行服务协议明确禁止使用爬虫、抓取工具，以及规避
Cookie、WAF 和非正常浏览识别机制。本项目没有实现这些绕过方式。

## 已验证边界

- 指数讨论页公开分页最多展示到 `100` 页；高活跃品种的第 `100` 页仍可能只回溯
  数月，不能覆盖五年。
- 网络档案保存的页面时间稀疏，且返回的是事后筛选的热门评论。若按发帖时间回放，
  会使用“后来变热门”的未来信息；若按档案抓取时间回放，又不代表真实采集频率。
- 历史页面显示的点赞、回复、转发和浏览量通常是当前累计值，不是当时快照。
- 因此，公开页面和网络档案只能用于解析器验证，不能用于收益回测。

## 可行数据路径

1. 取得雪球或授权数据商的原始点时数据/API，并保留授权证明。
2. DataSeed 公开产品页列出的 `D1704` 覆盖 `2011-07` 至 `2025-09`，字段包括帖子
   时间、正文和互动量；是否包含“发帖时点原始正文”和互动历史快照，需要在购买前
   向供应商书面确认。
3. FactSet Marketplace 列有 Xueqiu Analytics，可评估其历史深度、盘中延迟、
   指数/股票覆盖和许可范围。
4. 从取得授权之日起运行增量流，保存首次观测正文和每次互动快照。积累期不足时只做
   仿真盘，不外推五年收益。
