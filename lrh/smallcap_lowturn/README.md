# smallcap_lowturn

日频 A 股小市值低换手策略，放在独立子目录，避免影响 qlib 主库和其他 `lrh` 策略。

## 策略假设

- 使用前一交易日收盘后的数据生成信号，下一交易日开盘调仓。
- 在非 ST、非退市名、非北交所、上市满一年、20 日均成交额不低于约 2000 万元的股票池中选股。
- 评分偏好小总市值、低 20 日换手、低 60 日波动，并加入很轻的 20 日动量约束，避免持续下跌个股。
- 默认持有 200 只，20 个交易日调仓一次，等权。
- 默认交易成本为单边 10 bps，调仓时按实际权重变化扣减。
- 调仓开盘价达到涨停时不新增买入，达到跌停时不卖出。

## 运行

在仓库根目录执行：

```powershell
python .\lrh\smallcap_lowturn\run_backtest.py --end-date 20260608
```

输出目录默认是：

```text
D:\github\qlib\lrh\smallcap_lowturn\report
```

核心输出：

- `summary.csv` / `summary.json`: 汇总指标
- `daily_returns.csv`: 日收益、成本、换手、回撤、基准收益
- `annual_returns.csv`: 分年收益
- `holdings.csv`: 每次调仓后的持仓和特征
- `dashboard.html`: Plotly 回测图
- `qlib_report/qlib_report.csv`: Qlib-compatible 日频报表输入

## 实盘注意

该策略不能证明未来继续保持高收益，只能说明在当前本地数据和假设下历史表现达到目标。实盘前至少还需要检查账户可交易市场权限、资金容量、冲击成本、停复牌/退市处理、成交回报延迟、委托失败重试和风控止损规则。
